# Donor Domain Slate

Pick 5-8 domains from **different clusters** (never six biology sub-fields). Each entry:
what that field is unusually good at, the words to search (its own vocabulary beats
your problem's words), and where its knowledge actually lives.

Rule for all of them: you are mining a **mechanism that resolves a conflict**, not a look.

---

## Canonical transfers (calibration, not inspiration)

Use these to check your own find against a known-good pattern: each one is
*structural* (the physics moved) and was verified at the destination's own scale.

| Donor | Target problem it solved | The move that made it real |
|---|---|---|
| Burr seed hooks | Reversible fastener (Velcro) | Verified hold/release cycles, not resemblance |
| Gecko setae (van der Waals) | Residue-free adhesion | Scaled to manufactured arrays; measured at relevant roughness |
| Kingfisher beak | Tunnel-boom noise / entry pressure | Aerodynamic, not \"shape looks nice\" — CFD then hardware |
| Termite mound thermodynamics | Building ventilation | Coupled model + building instrumentation |
| Lotus leaf wettability | Self-cleaning surfaces | Failed on real dirty/oily surfaces — the cautionary case |
| Pinecone hygromorph | 4D-printed actuators, adaptive textiles | Loop-verified humidity response |
| Miura-ori folding | Deployable solar arrays, surgical stents | Fold kinematics + cycle testing |
| Kirigami cuts | Stretchable electronics | Strain-to-elongation measured |
| Jacquard punch cards → punched-card control | Programmable automation | Sequencing abstraction, not weaving |
| Antikythera gearing | Differential/mechanism reconstruction | Tooth-count reverse engineering |
| Trap-jaw ant latch | Snap-through bistable actuators | Energy release measured |
| Humpback flipper tubercles | Fans, turbines, heat-exchanger fins | Replicates tested in wind/water tunnels |
| Owl feather serrations | Wind-turbine trailing-edge noise | Aeroacoustic measurement |
| Wax/soot nano-structures | Structured surfaces (thermal, optical) | A cautionary case: exotic patterning failed on production economics |
